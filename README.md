# DSA Leveling

A personal repository documenting my DSA preparation.

## My Approach

I focus on understanding how a solution evolves:

Brute Force → Better → Optimal

The goal is not only to solve problems, but to understand:

- Why the brute-force solution works
- What makes it inefficient
- What bottleneck can be removed
- How the improved solution works
- Why the final complexity is better
